# Monogram star

![Rendered in a hoop](feed.jpg)

[Stitch chart](chart.png) · [Detail check](detail-check.png)

- **Size:** 80 × 80 stitches. On 14-count Aida that's 5.7 × 5.7 in; on 18-count, 4.4 × 4.4 in.
- **Fabric:** cream Aida.
- **Shape match:** 0.93 (1.00 is a perfect match with the original art).
